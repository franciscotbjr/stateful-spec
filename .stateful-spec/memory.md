## Key Decisions

> Important decisions that affect how the AI should work on this project. For detailed ADRs, see `history/` files.

- This project is documentation-only (Markdown). There is no application code, build system, or runtime dependencies.
- Operation prompts are placed as native Cursor rule files (`.cursor/rules/<name>.mdc`) rather than in `.stateful-spec/operations/`.
- `.stateful-spec/methodology/` references the root `methodology/` directory rather than copying it, because this repo IS the methodology source. This avoids duplication drift in a self-referential project.
- Non-trivial work must use an iteration file under `.stateful-spec/history/` (see `AGENTS.md` **Iteration tracking**); `resume-session` and `save-session` prompts describe direct-task entry and retroactive saves.
- This repo's agents operate under the SDD-specialist persona at `.stateful-spec/persona.md` — **the persona of Stateful Spec itself**, not shipped downstream. Ambient binding with carve-outs (`packages/` code → engineer posture; protocol weight scales with task size); §6 checklist logged in the open iteration as the Sensor. The Persona section in root `AGENTS.md` is a deliberate self-only divergence from the template. (Iteration 022)
- O-010 (multi-repo Workspace) is delivered as one iteration per milestone (M1–M7). Its design decisions live in iteration 024's **Decisions Made** (resolve the file via the History Index); each milestone iteration cites the specific rows (e.g. "024 Plan Q8a") instead of re-reading the whole central file (~51 KB). Remove this line when M7 closes. (Iteration 024)
